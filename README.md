# Kimi Cleaner - Kimi 会话批量清除助手

一个简单的浏览器扩展，用于一键批量删除 Kimi 智能助手 (kimi.moonshot.cn / www.kimi.com) 的历史会话。

##  功能特点

*   **一键清理**：告别手动一个一个删除的烦恼，自动勾选并删除当前页面的历史会话。
*   **智能跳转**：如果你不在历史记录页面，插件会自动帮你跳转到 `chat/history` 页面并自动开始清理。
*   **安全确认**：脚本模拟用户点击行为，自动处理确认弹窗。

## 📦 安装说明

由于本项目主要供个人或开发者使用，可以通过“加载已解压的扩展程序”方式安装：

1.  **下载代码**：将本项目下载或 Clone 到本地文件夹。
2.  **打开扩展管理页面**：
    *   Chrome 浏览器地址栏输入：`chrome://extensions/`
    *   Edge 浏览器地址栏输入：`edge://extensions/`
3.  **开启开发者模式**：在页面右上方找到“开发人员模式” (Developer mode) 开关并打开。
4.  **加载插件**：
    *   点击左上角的“加载已解压的扩展程序” (Load unpacked) 按钮。
    *   选择包含 `manifest.json` 文件的本项目文件夹 (`kimi-cleaner`)。

## 🚀 使用方法

1.  安装完成后，在浏览器工具栏找到 **Kimi Cleaner** 的图标（如果没有显示，请在扩展拼图中点击固定）。
2.  点击插件图标，弹出操作窗口。
3.  点击红色的 **“批量删除所有会话”** 按钮。
    *   **情况 A**：如果你已经在 Kimi 的“历史会话”页面，程序会直接开始执行删除操作。
    *   **情况 B**：如果你在 Kimi 的对话页面或其他页面，程序会自动跳转到历史页面，等待页面加载完成后自动执行删除。
